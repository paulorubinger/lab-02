# 📊 Lab02 – Estudo das Características de Qualidade de Sistemas Java

Este projeto tem como objetivo analisar atributos de qualidade interna de sistemas open‑source desenvolvidos em Java, correlacionando métricas de produto com características do processo de desenvolvimento dos repositórios mais populares do GitHub.

---

# 🎯 Objetivo do Projeto

O objetivo principal deste laboratório é investigar a relação entre:

* Popularidade dos repositórios
* Tamanho do código
* Maturidade dos projetos
* Atividade de desenvolvimento

com métricas de qualidade de software calculadas automaticamente pela ferramenta **CK**.

---

# 💬 Questões de Pesquisa

O trabalho busca responder às seguintes questões:

**RQ01** – Qual a relação entre a popularidade dos repositórios e suas características de qualidade?

**RQ02** – Qual a relação entre a maturidade dos repositórios e suas características de qualidade?

**RQ03** – Qual a relação entre a atividade dos repositórios e suas características de qualidade?

**RQ04** – Qual a relação entre o tamanho dos repositórios e suas características de qualidade?

---

# 📊 Métricas de Qualidade Utilizadas

As seguintes métricas são calculadas pela ferramenta CK:

* **CBO** – Coupling Between Objects
* **DIT** – Depth of Inheritance Tree
* **LCOM** – Lack of Cohesion of Methods

---

# 📈 Métricas de Processo Utilizadas

As seguintes características dos repositórios serão analisadas:

* Popularidade (número de estrelas)
* Tamanho (linhas de código)
* Atividade (número de releases)
* Maturidade (idade do repositório)

---

# 📄 Entregas do Trabalho

### Sprint 1

* Lista dos 1.000 repositórios Java mais populares
* Script de automação de clone
* Script de execução do CK
* Arquivo CSV com métricas de 1 repositório

### Sprint 2

* Métricas de todos os 1.000 repositórios
* Análise estatística
* Gráficos de correlação
* Relatório final
